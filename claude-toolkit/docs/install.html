claude-toolkit · v0.6.0

Install in any project

Set it up once with the terminal CLI and it's live in every project — 30 skills, 14 agents, 4 MCP tools, safety hooks. No npm install, no per-project setup.

The reliable way

Use the claude plugin CLI in a terminal

This works everywhere — including the VS Code / IDE extensions, where the interactive /plugin slash command does not exist. The source is owner/repo (not github:owner/repo).

1

Open a normal terminal

Any shell prompt (the line ending in $). You do not need to start Claude Code first for these.

2

Add the marketplace and install

$ claude plugin marketplace add Praneeth-496/claude-toolkit
$ claude plugin install claude-toolkit

Installs at user scope, enabled by default. Zero dependencies to install.

3

Restart Claude Code

Close and reopen the Claude Code panel/window, or start a new chat. Plugins are only loaded at session start — a session opened before installing won't show it.

4

Verify

$ claude plugin list              # claude-toolkit -> Status: ✔ enabled
$ claude plugin details claude-toolkit   # full inventory + token cost

Then inside the Claude Code chat, type /claude-toolkit: to see all 30 skills, and /mcp to see the 4 MCP tools.

Important

Where each command goes

The single biggest source of confusion. Two different places:

▸ terminal (bash) — prompt ends in $
claude plugin marketplace add …
claude plugin install …
claude plugin list
▸ inside Claude Code chat
/claude-toolkit:cove-verifier
/toolkit-init
/mcp
Never type /plugin in bash. It is not a Linux program — bash answers bash: /plugin: No such file or directory. And /plugin is not available in the VS Code extension at all. That is exactly why this guide uses claude plugin … (a real terminal command) instead.

Troubleshooting

If something went wrong
bash: /plugin: No such file or directoryYou typed a slash command in bash. Use the terminal CLI: claude plugin marketplace add Praneeth-496/claude-toolkit.
/plugin isn't available in this environmentYour VS Code/IDE extension has no interactive plugin command. Use the terminal CLI (same as above).
Invalid marketplace source formatDrop the github: prefix. The CLI wants owner/repo → Praneeth-496/claude-toolkit.
Status: ✘ disabledIt got turned off. Re-enable: claude plugin enable claude-toolkit.
Installed but not showing in chatYou didn't restart. Open a fresh Claude Code session.
⚠ Do not paste claude plugin disable claude-toolkit from any reference list — it switches the plugin OFF. To turn it back on: claude plugin enable claude-toolkit.

Updating

Pull a new version
$ claude plugin marketplace update claude-toolkit-marketplace

It's user-scope, so one install covers every project on the machine — no per-project setup. Prefer files committed into a specific repo instead? See the install.sh copy-installer in ADD-TO-ANY-PROJECT.md.

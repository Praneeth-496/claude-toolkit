Making the toolkit genuinely agentic

A research-backed plan to grow beyond 8 review agents into a disciplined set of verifiers, anti-hallucination checks, orchestration loops, and idea-exploration agents — without rebuilding what the ecosystem already covers.

Where we are

Strong on review, thin on verification, orchestration loops, and ideation

The current 8 agents cover review well — code-reviewer, security-auditor, simplifier, test-runner, doc-writer, plus three "thinking" agents: adversary (steelman), fact-checker (repo-grounded claims), flow-auditor (reasoning-chain audit).

An inventory of your installed plugins shows orchestration and consensus are already saturated elsewhere (ruflo swarm coordinators, cc10x planner/verifier, ~95 project agents incl. byzantine/raft/gossip consensus, swarm topologies). So the real, unfilled gaps are narrower than "add lots of agents":

  1. Only one fact-checker, and it only grounds against this repo — no external/citation verifier, no sampling-based hallucination check, no Chain-of-Verification.
  2. No orchestration loops — council and orchestrate are one-shot; nothing iterates to convergence or runs a judged debate.
  3. No ideation agents — creativity exists only as one-shot skills (devil, critique, 10x).
  4. No convergence step — divergent generation has no paired "cluster, score, shortlist" closer.

Proposed additions

Eleven components across four buckets, each tied to a primary source
A.Verification & anti-hallucination— the highest-ROI bucket: coding gives real external signals to check against
cove-verifierP1

Chain-of-Verification: takes a claim/answer, generates independent verification questions, answers them in isolation, and revises/flags anything contradicted.

agentopusread-only
Dhuliawala et al. 2023, CoVe[1] · tools: Read, Grep, Web
citation-auditorP1

Per-claim external grounding. For every factual sentence, retrieves evidence and labels it Supported / Unsupported / Contradicted with a source. Catches fake papers, wrong DOIs, invented APIs.

agentsonnetopus*read-only
RARR (Gao 2022) + AIS (Rashkin 2021) + "According-to"[4][5] · tools: Web, Read, Grep
consistency-checkerP1

SelfCheckGPT-style triage: re-samples a claim N times and flags sentences that diverge across samples. Source-free; escalates suspicious lines to citation-auditor.

skillhaiku ×Nsonnet
Manakul et al. 2023, SelfCheckGPT[2] · model-only, no external deps

Your existing fact-checker stays as the repo-grounding layer; these add the external, sampling, and CoVe layers it lacks. A "second opinion" check is free: run fact-checker under a different model for cross-model corroboration.

B.Orchestration loops— what council/orchestrate don't do: iterate and debate
refine-loopP2

Evaluator–optimizer loop: a generator drafts, an evaluator runs the real check (tests, or verify-result-claim against a results JSON), writes a critique, generator retries. Stops on pass or 3 iterations.

skillgen: sonneteval: opus
Reflexion (Shinn 2023) + Self-Refine (Madaan 2023)[8][9] · gated on an external signal (see principles)
debateP2

Adversarial multi-round consensus for contested-correctness questions ("is this concurrency-safe?"). 2–3 agents read each other and revise; a judge declares consensus. Capped at 2–3 rounds.

skilldebatersjudge
Du 2023 + Liang 2023 (divergent-thinking debate)[6][7]
voteP3

Self-consistency wrapper for discrete answers (classification, "which of these 3?"). Sample k=5, majority-vote, report agreement. Cheapest reliability boost there is.

skillhaiku/sonnet ×5
Wang et al. 2022, Self-Consistency[3] · only for votable answers
C.Ideation & creativity— essentially absent today; diversity-forcing is non-negotiable
ideatorP2

Pure divergent generator. Emits N ideas under diversity-forcing: randomly-sampled ordinary personas (not "Steve Jobs"), constraint variation, and an explicit "now diverge from your previous ideas" step. No self-judging.

agentsonnetread-only
Deng/Brucks/Toubia 2025; homogenization: Anderson 2024, Nature HB 2025[11][12]
synthesizerP2

The convergent closer. Clusters many raw ideas, scores them against explicit criteria, and recommends a shortlist with rationale. The missing second half of divergent → convergent.

agentopusread-only
Guilford divergent/convergent; over-generate-then-cluster[10]
D.Structured critique— assumption-level, beyond the flaw-level critique you already have
premortemP3

Assumes the plan already failed and enumerates the causes with likelihood/impact, then top mitigations. Prospective hindsight ≈ +30% at naming real reasons.

agentsonnetread-only
Klein, HBR 2007[13]
assumption-surfacerP3

Toulmin-maps a claim or plan and lists the implicit warrants it silently depends on — the unstated "this only works if…" conditions.

agentsonnetread-only
Toulmin argument model[14]
/brainstorm pipelineP3

A skill that wires the loop: reframe (How-Might-We) → ideator (diversity-forced) → premortem + assumption-surfacer stress-test → synthesizer shortlist. The discipline, made one command.

Design principles

Evidence-based, and a few of them are counterintuitive
  • Every verifier must rest on an external signal — web retrieval, a corpus, code/test execution, or independent re-sampling. Pure "reconsider your answer" introspection degrades reasoning. Huang 2023: CommonSenseQA collapsed 75.8% → 38.1% after one self-correction round[15]
  • Prefer voting over elaborate debate at matched cost. Multi-agent debate is largely dressed-up majority voting and often loses to plain self-consistency. Huang 2023: debate 83.0% vs self-consistency 88.2% at 9 responses — so cap debate rounds at 2–3 and reach for vote when the answer is discrete.
  • Debias the judge. LLM-as-judge has position, verbosity, and self-preference bias. Swap positions and average, use the strongest model as judge, and never let a model judge its own output. Zheng 2023[16]
  • Force idea diversity by default. LLM ideation homogenizes (different users converge on the same idea). Use random ordinary personas, over-generate then cluster. Deng 2025: ordinary-persona + CoT beat human collective diversity by ~26%; celebrity personas cluster too densely
  • Spend multi-agent tokens only when it pays. Multi-agent helps on broad, parallelizable, high-value tasks (~15× tokens); a single strong agent usually wins on tightly-coupled/coding work. Anthropic 2025; MAST 2025: role-team ChatDev scored 25% with GPT-4o[17][18]

What we will not build

Anti-bloat — already covered or evidence says skip
swarm / topology coordinators
ruflo + project agents already ship hierarchical/mesh/adaptive.
distributed consensus
byzantine / raft / gossip / quorum exist in the project agents — infra, not opinion panels.
more code-reviewers
review is saturated across toolkit + cc10x + ruflo.
role-team frameworks
CAMEL/MetaGPT-style teams underperform (MAST); council + orchestrate suffice.
naive self-refine loops
harmful without an external signal — see principles.

Rollout

Three phases, smallest valuable slice first
Phase 1 — verification (your core ask)

cove-verifier · citation-auditor · consistency-checker

Highest ROI and lowest risk: all read-only, all rest on external signals (repo, web, re-sampling). Directly attacks hallucination. Ships as 2 agents + 1 skill.

Phase 2 — loops & ideation

refine-loop · debate · ideator · synthesizer

Adds iteration, judged debate, and the divergent→convergent pair. refine-loop plugs straight into your existing verify-result-claim + SLURM test runs.

Phase 3 — structured critique & the pipeline

premortem · assumption-surfacer · /brainstorm · vote

Nice-to-have polish and the one-command brainstorm pipeline. Optional method pack (six-hats, SCAMPER, first-principles) if you want them.
